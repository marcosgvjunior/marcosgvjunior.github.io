## Purpose

This folder documents the public portfolio site as a software project. It
explains architecture, content modeling, design decisions, local execution, and
release quality.

## Reading Path

- [Architecture](ARCHITECTURE.md): layout, data, assets, and runtime
  boundaries.
- [Flow](FLOW.md): browser, Jekyll, and Docker execution flow.
- [Logic Flow](LOGIC_FLOW.md): Mermaid map of templates, data, and JavaScript
  behavior.
- [Content Model](CONTENT_MODEL.md): how portfolio evidence maps to pages and
  data files.
- [Design System](DESIGN_SYSTEM.md): visual principles, image usage, and
  component rules.
- [Local Development](LOCAL_DEVELOPMENT.md): Docker-first local workflow.
- [Release Checklist](RELEASE_CHECKLIST.md): content and technical checks before
  updates are pushed.

## Documentation Standard

Docs help a reader understand how the site is built, how content is structured,
and how quality is checked. They are written for technical reviewers evaluating
the repository as a small web project.
